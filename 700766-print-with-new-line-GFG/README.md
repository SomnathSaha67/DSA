# [Print with New Line](https://www.geeksforgeeks.org/problems/the-new-line/1)
## Easy
There is a string&nbsp; "Geeks for Geeks", print each word on a separate line.
Note: No input required for this problem.
Example :
Input: Not Required
Output: Geeks        for
        Geeks
Explanation: Each word is printed on a separate line.
