# [Adding One to Array](https://www.geeksforgeeks.org/problems/adding-one2529/1?itm_source=geeksforgeeks&itm_medium=article&itm_campaign=practice_card&selectedLang=python3)
## Easy
Given a non-negative integer(without leading zeroes) represented as an array arr. Your task is to add 1 to the number (increment the number by 1). The digits are stored such that the most significant digit is at the starting index of the array.
Examples:
Input: arr[] = [5, 6, 7, 8]
Output: [5, 6, 7, 9]
Explanation: 5678 + 1 = 5679
Input: arr[] = [9, 9, 9]
Output: [1, 0, 0, 0]
Explanation:&nbsp;999 + 1 = 1000

Constraints:1 ≤ arr.size() ≤ 1060 ≤ arr[i] ≤ 9There are no leading zeros in the input number.&nbsp;
