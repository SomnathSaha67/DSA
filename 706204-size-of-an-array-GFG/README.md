# [Size of an Array](https://www.geeksforgeeks.org/problems/size-of-an-array/1?selectedLang=python3)
## Easy
Given an array arr[], find the size of the array.
Examples :
Input: arr[] = [1, 2, 3]
Output: 3
Explanation: The size of the array is 3.
Input: arr[] = [1, 2, 3, 5, 4]
Output: 5
Explanation: The size of the array is 5.
Constraints:1 ≤ |arr| ≤ 101 ≤ elements of arr ≤ 10
