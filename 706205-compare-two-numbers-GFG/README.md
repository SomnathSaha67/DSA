# [Compare Two Numbers](https://www.geeksforgeeks.org/problems/compare-two-numbers/1)
## Easy
Given two integers a and b, print 1 if a is greater than b; otherwise, print 0.Example :Input: a = 4, b = 6
Output: 0Explanation: Since 4 is smaller than 6, the output is 0.Input: a = 2, b = -9
Output: 1Explanation: Since 2 is greater than -9, the output is 1.Input: a = 5, b = 5
Output: 0Explanation: Since both numbers are equal, a is not greater than b.
