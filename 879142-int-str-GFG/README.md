# [Int Str](https://www.geeksforgeeks.org/problems/int-str--164410/1)
## Easy
Given three inputs that are stored in the variables a, b, and c. You need to print a a times and b b&nbsp;times&nbsp; in a single line separated by c.
Examples:
Input: a = 6, b = 4, c = &amp;
Output: 666666&amp;4444
Explanation: 6 printed 6 times and 4 printed 4 times separated by c = &amp;.
